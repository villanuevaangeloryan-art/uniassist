# UNIASSIST

## App Description

**UNIASSIST** is an Android application designed to help university students manage their academic life more efficiently.  
The app provides easy access to campus information, academic tasks, schedules, and announcements in one place.

During the Prelim phase, the app focuses on:
- Mock login authentication using hardcoded credentials
- A dashboard with a welcome message and navigation menu
- A Campus Information module showing a static list of departments and contact details
- Basic UI built using Jetpack Compose
- Session handling using SharedPreferences

The app is developed using **Kotlin**, **Android Studio**, and follows the **MVVM architecture**. It will evolve over the semester with more features and better code structure.
